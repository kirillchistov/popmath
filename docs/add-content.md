# Как добавлять контент

Два пути, одна схема. Git-темы и задачи из админки не должны разъезжаться по полям.

## Что выбрать

| Путь | Когда | Куда попадает |
|---|---|---|
| Форма на `/tutor` | Одна задача или опора за 5–10 минут, сразу ученику | `data/content-overlay.json` (не в git) |
| JSON в репозитории | Пачка задач, новый остров, картинки, опора, которую хотим сохранить | `content/topics/<id>.json` |

Оверлей сливается с git при чтении: та же `Task` и та же `Support`. Если id совпал, побеждает оверлей.

Карта и очередь берут **уже существующие** острова. Новый остров одной формой не создать — только задача или опора к известной теме.

## Острова сейчас

`equations` · `inequalities` · `word` · `functions` · `geometry`

| id | Акцент | Слоты ОГЭ | Антиблокер |
|---|---|---|---|
| `equations` | `eq` | 8, 9 | нет |
| `inequalities` | `ineq` | 7, 13 | нет |
| `word` | `word` | 1–5, 6, 10, 12, 14 | страх пустого листа |
| `functions` | `func` | 11 | нет |
| `geometry` | `geo` | 15–19 | 2 минуты узнавания |

Новый остров — это не только JSON. Нужно добавить файл в `content/topics/`, импорт в `lib/content.ts`, цвет `--theme-*` в `app/globals.css` и символ в `TopicList`. Пока не надо: см. [content-roadmap.md](content-roadmap.md).

## Задача

Минимум: условие, ответ, «как надо», ловушка, тема, время.

```json
{
  "id": "equations-10",
  "topic_id": "equations",
  "prompt": "Реши: 2x + 3 = 11",
  "answer": "4",
  "kind": "practice",
  "explain_ok": "2x = 8, x = 4.",
  "explain_trap": "Ошибка — вычесть 3 из 11 и забыть деление.",
  "review_title": "Сначала перенос, потом деление",
  "time_sec": 45,
  "tags": ["уравнения", "огэ-9"],
  "trap_answers": ["7", "8"],
  "image": "/images/example.svg"
}
```

Правила:

- `id` только латиница, цифры и дефис. Кириллица ломает URL `/task/<id>`.
- В git id лучше осмысленный: `geo-9`, `word-10`. В админке id выдаётся сам: `admin-<тема>-<время>`.
- `kind` для практики всегда `practice`.
- `answer` — то, что ученик вводит в одно поле. Несколько корней через `;`: `2;3`. Десятичная и `0,75`, и `0.75` подойдут.
- `trap_answers` — частые неверные ответы. По ним система ставит `inattention`.
- `image` необязателен. Файл кладём в `public/images/` и пишем путь от корня сайта, например `/images/geo-rect-grid.svg`. Конструктора фигур нет: только статичная картинка.
- `time_sec` 15–300. На старте 45–60, не экзамен.
- Тон: коротко, без «молодец» и без «это должен знать каждый».

В админке те же поля. Картинку можно вписать в поле «Картинка, если нужна».

После сохранения задачу можно сразу посадить ученику: «Дать ученику» на `/tutor`. Она появится на «Сегодня», пока не будет верного ответа.

## Опора

3–5 шагов, метафора, якорь. Не конспект главы.

```json
{
  "id": "support-example",
  "title": "Короткое имя хода",
  "metaphor": "Образ в одну фразу.",
  "anchor": "Что поймать глазами до счёта.",
  "steps": [
    "Шаг 1",
    "Шаг 2",
    "Шаг 3"
  ],
  "body": "Запасная строка, если шаги не отрисовались."
}
```

В git опора лежит в массиве `supports` темы. В админке шаги — каждый с новой строки.

Для геометрии опора «как узнать фигуру» идёт **до** решения. Не пишите доказательство в первой карточке.

## Тема целиком

Поля острова: `id`, `title`, `badge`, `exam_slots`, `phrase`, `metaphor`, `accent`, `steps` (5), `traps`, `supports`, `tasks`.

`exam_slots` — номера ОГЭ, не наши внутренние id. Они нужны тьютору и родителю, ученик их на карте не видит как «задание 19».

## Квиз

`content/quiz.json`. У вопроса должен быть `topic_id` существующего острова, если сюжет уже живой. Геометрические вопросы квиза (15–19 в заготовке) смотрят на `geometry`.

Новые вопросы в квиз не добавляйте без нужды: квиз — диагностика, не банк.

## Самопроверка

Отдельный набор `/check` берёт id из `CHECK_TASK_IDS` в `lib/content.ts`. Если задача должна уметь тренировать чеклист сама по себе — добавьте её id туда. Не раздувайте список.

## Картинки

1. Положите SVG или PNG в `public/images/`.
2. Имя файла латиницей.
3. В задаче укажите `image`.
4. Подпись не нужна: условие говорит, на что смотреть.
5. Клетчатые задачи — сетка 1×1, без лишних украшений.

Не используйте сканы целых уроков из `res/lessons`. Адаптируйте одну штуку в наш формат.

Сюжеты 1–5 с [time4math](https://time4math.ru/oge) и похожих задачников: брать тип хода (соответствие, масштаб, площадь, процент, выбор из таблицы), не формулировку и не таблицу автора. Свои числа, короткий prompt, один ответ.

## Проверка после добавления

1. `npm run build` или хотя бы открыть тему учеником.
2. Ввести верный ответ и один ответ из `trap_answers`.
3. Если задача для конкретного человека — посадить в очередь и глянуть «Сегодня».
4. Кириллица в файле: сохранять UTF-8. Если вместо букв «?», файл писали в C-локали.

## Чего не делать

- WYSIWYG и загрузка Word.
- Новый остров «на всякий случай».
- Геометрический конструктор.
- Полный пробник в ленту задач.
- Рейтинг, лиги, стыд в формулировках.
