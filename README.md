# Матешка

Закрытый тренажёр ОГЭ по математике для небольшой группы: ученик с пробелами и тревогой, родитель рядом и тьютор, который ведёт занятия.

Это не банк заданий и не курс «на весь кодификатор». Сначала короткий квиз, потом одна тема с алгоритмом и ловушками, затем разбор «как надо / как не надо». Ошибка — сигнал, а не приговор.

План разработки: [docs/roadmap.md](docs/roadmap.md). Как добавлять задачи: [docs/add-content.md](docs/add-content.md). Очередь тем по ФИПИ: [docs/content-roadmap.md](docs/content-roadmap.md).

## Что уже работает

- вход по логину для закрытой группы;
- стартовый квиз из 15 коротких вопросов;
- 5 тем: уравнения, неравенства, текстовые задачи, функции, геометрия;
- практика с нормализацией ответа, чеклистом и самотегом ошибки;
- тонкий tutor-admin: когорта, форма задачи и опоры, очередь ученику;
- недельный отчёт родителю по ссылке, без отдельного приложения;
- разбор попыток у ученика и правка тега ошибки у тьютора.

## Быстрый старт

Нужны Node.js 20+ и npm.

```bash
make install
make dev
```

Откройте http://localhost:3000

`make dev` сам создаст `.env.local` из `.env.example`, если файла ещё нет. Если `.env.local` уже есть, он не перезаписывается.

Другие команды:

| Команда | Что делает |
|---|---|
| `make install` | Ставит зависимости |
| `make env` | Копирует `.env.example` → `.env.local`, только если его нет |
| `make dev` | Локальный сервер |
| `make build` | Production-сборка |
| `make start` | Запуск собранного приложения |

## Демо-вход

| Роль | Логин | Пароль |
|---|---|---|
| Ученик | `demo` | `demo@demo5678` |

На странице входа: логин `demo`, пароль `demo@demo5678`.

Тьюторский логин задаётся в `.env.local` (`AUTH_USERS`). В примере это `kirill` / `changeme`. Свои пароли держите только в `.env.local`, не в git.

Формат списка людей:

```text
login:password:role,login2:password2:role
```

Роль — `student` или `tutor`. Если роль не указана, человек считается учеником.

## Как устроен проект

```text
app/                 экраны и BFF
components/          квиз, практика, разбор
content/topics/      пять тем в JSON
content/quiz.json    стартовый квиз
public/images/       статичные рисунки к задачам
lib/                 auth, контент, store попыток
data/                попытки, планы и admin-контент, не в git
docs/roadmap.md      этапы разработки
docs/add-content.md  как добавлять задачи и опоры
docs/content-roadmap.md  очередь тем по ФИПИ
```

Попытки пишутся в `data/attempts.json`. Для локальной группы этого достаточно. На Vercel без диска файл не сохранится — позже заменим реализацию в `lib/store.ts`, интерфейс останется тем же.

## Полезные адреса

| Путь | Кто | Что |
|---|---|---|
| `/login` | все | вход |
| `/` | ученик | сегодня: квиз и темы |
| `/quiz` | ученик | стартовый квиз |
| `/topic/equations` | ученик | тема и практика |
| `/topic/geometry` | ученик | геометрия: сначала узнавание |
| `/review` | ученик | разбор своих ошибок |
| `/tutor` | тьютор | когорта, формы, очередь, ссылка родителю |
| `/task/<id>` | ученик | одна задача, в том числе от тьютора |
| `/digest/<token>` | родитель | недельная картина, без входа, срок 2 недели |

Ссылку дайджеста тьютор собирает на `/tutor` («Собрать неделю») и копирует или отправляет письмом. Старые токены живут до 14 дней. Раз в понедельник cron `GET/POST /api/cron/digest` с заголовком `Authorization: Bearer $CRON_SECRET` собирает новые ссылки на всю когорту. Локально: `PORT=3001 make digest`.
