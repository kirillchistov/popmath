# Быстрый ход

Закрытый тренажёр ОГЭ по математике для небольшой группы: ученик с пробелами и тревогой, родитель рядом и тьютор, который ведёт занятия.

Это не банк заданий и не курс «на весь кодификатор». Сначала короткий квиз, потом одна тема с алгоритмом и ловушками, затем разбор «как надо / как не надо». Ошибка — сигнал, а не приговор.

План разработки: [docs/roadmap.md](docs/roadmap.md).

## Что уже работает

- вход по логину для закрытой группы;
- стартовый квиз из 15 коротких вопросов;
- 4 темы: уравнения, неравенства, текстовые задачи, функции;
- практика с нормализацией ответа и самотегом ошибки;
- разбор попыток у ученика и список попыток у тьютора.

## Быстрый старт

Нужны Node.js 20+ и npm.

```bash
make install
make dev
```

Откройте http://localhost:3000

`make dev` сам создаст `.env.local` из `.env.example`, если файла ещё нет. Если `.env.local` уже есть, он не перезаписывается.

Другие команды:

| Команда | Что делает |
|---|---|
| `make install` | Ставит зависимости |
| `make env` | Копирует `.env.example` → `.env.local`, только если его нет |
| `make dev` | Локальный сервер |
| `make build` | Production-сборка |
| `make start` | Запуск собранного приложения |

## Демо-вход

| Роль | Логин | Пароль |
|---|---|---|
| Ученик | `demo` | `demo@demo5678` |

На странице входа: логин `demo`, пароль `demo@demo5678`.

Тьюторский логин задаётся в `.env.local` (`AUTH_USERS`). В примере это `kirill` / `changeme`. Свои пароли держите только в `.env.local`, не в git.

Формат списка людей:

```text
login:password:role,login2:password2:role
```

Роль — `student` или `tutor`. Если роль не указана, человек считается учеником.

## Как устроен проект

```text
app/                 экраны и BFF
components/          квиз, практика, разбор
content/topics/      четыре темы в JSON
content/quiz.json    стартовый квиз
lib/                 auth, контент, store попыток
data/                локальные попытки, не в git
docs/roadmap.md      этапы разработки
```

Попытки пишутся в `data/attempts.json`. Для локальной группы этого достаточно. На Vercel без диска файл не сохранится — позже заменим реализацию в `lib/store.ts`, интерфейс останется тем же.
